# RL-041: Add structured and redactable explanation traces

## Objective

Explain why a decision occurred using stable trace data for evaluated, skipped, missing, errored, and conflict-resolved nodes.

## Technical constraints

- Type: `story`.
- Epic: `RL-E05`.
- Depends on: `RL-030`, `RL-031`.
- Trace detail is selectable as none, summary, or full.
- Tracing must not change normative evaluation outcomes or ordering.
- Sensitive values are redacted by default unless explicitly classified safe.

## Functional requirements

1. Define a versioned trace schema with decision, rule, expression, fact, cache, action, conflict, and diagnostic records.
2. Record stable plan node and source IDs, outcome, evaluated/skipped reason, and parent-child relationships.
3. Record resolver duration, cache state, and safe failure codes without requiring fact-value capture.
4. Implement value-classification hooks for omit, type-only, hash, preview, or full-value trace policies.
5. Enforce trace entry, depth, string-size, and total-byte budgets.
6. Ensure short-circuited and canceled work has an explicit trace state rather than appearing absent.
7. Provide a deterministic JSON serializer and a human-readable explanation renderer.
8. Add tests proving tracing levels and redaction do not alter decisions.

## Quality requirements

- Full-value tracing must be an explicit host decision and clearly documented as sensitive.
- Trace timings may vary, but canonical structural comparison must support ignoring volatile timing fields.
- Trace hooks must not throw into evaluation; hook failures follow a documented policy.
- Summary tracing overhead must be measured by RL-050.

## Out of scope

- Persisting traces to a database.
- OpenTelemetry exporter implementation.
- Natural-language explanations generated by an LLM.

## Acceptance criteria

- Every rule result can be traced to evaluated and skipped expression nodes.
- Missing, error, cache, cancellation, and conflict decisions are distinguishable.
- Default traces contain no values classified secret.
- Enabling any trace level leaves normative decision output unchanged.
